# Λ–原子核KF解析の検証用QA（2026-09-30）

8個すべてのROOT入力について、解析ログに入力イベントをちょうど10,000件処理し、
`status=0`で終了したことが記録されてから読み込みました。各PDFは4ページです。
最初のページに包括的なΛ候補とペアに含まれるΛの質量、およびSE/MEの質量対k*を示し、
続いて信号領域、左サイドバンド、右サイドバンドのSE/MEと補正前CFを示します。
設定されたcent9の0–8ビンを合算してからCFを正規化しています。
サイドバンド差引きやΦ用の質量フィットモデルは適用していません。

信号チャネルでペアに使用するΛは、すでに**質量中心から±3σ**で選択しています。
4核種で共通の既存設定は、`lambdaSignalMean: 1.11596`、
`lambdaSignalSigma: 0.00296`、`lambdaSignalNSigma: 3.0`です。
したがって信号質量窓は**[1.10708,1.12484] GeV/c²（両端を含む）**です。
以下の「信号の正規化領域SE/ME数」は、この信号窓内のペアについて数えています。

この±3σの信号選択は、包括的なΛ質量ヒストグラムや質量対k*に残す
全質量範囲1.05–1.25 GeV/c²とは別です。また、後述の比較図の表示・面積正規化窓
**[1.10,1.14) GeV/c²**も信号選択窓ではありません。
比較図の表示窓内カウントを±3σ内の収量と読み替えないでください。
ここでは既存の設定を明記しただけで、解析・図・YAMLは変更していません。

「信号の正規化領域SE/ME数」は、信号質量領域のうち、設定された正規化区間
0.5 <= k* < 1.0 GeV/cだけを数えたものです。Λの総収量や検出効率では**ありません**。
8種類の信号チャネルはすべて正規化領域に非ゼロのカウントがありますが、
特に4HeのSE統計は限られています。「未定義」は正規化領域のカウントの少なくとも
一方がゼロであることを意味し、サイドバンドのヒストグラム全体が空であることを
意味しません。未定義のCFは図中に明記し、個々のMEがゼロのビンも、
測定されたCFのゼロ値として描かず省略しています。

検証結果：最終的な8出力はすべてROOT5 QAの終了コードがゼロでした。
Ghostscriptでも各PDFが4ページであり、全32ページの描画量が非ゼロであることを確認しました。
3.85 GeVのdの1ページ目をPNG化して目視確認し、必要な4図とΛピークが存在することを確認しました。
13.5 GeVの4He信号ページもv2修正後に目視確認し、正のCFの点が表示されることを確認しました。
これらはQA出力の検証であり、低統計CFの統計精度や物理解釈を保証するものではありません。

ログは`rootfile/femto_lambda_kf_validation_20260930/provenance/qa_*.log`にあります。
最初の`qa_3p85_d.log`では、PDFが作成される前にROOT5のディレクトリ名バッファの問題が
見つかりました。このログは保存しています。修正後に成功した実行のログは
`qa_3p85_d_retry1.log`です。修正では、再帰的にmkdirを呼ぶ前に
`gSystem->DirName()`の結果をTStringへコピーし、空でないPDFが実際に
書き込まれたことも確認するようにしました。既存PDFやROOTファイルは上書きしていません。

上の表にリンクした**v2**のPDFを使用してください。初版PDFも検証記録として残しています。
目視検査で、複製したCFヒストグラムがSEの表示上限を引き継ぎ、正のCFの点が
表示範囲外に切れていることが見つかりました。v2では、CFの表示範囲を求める前に
引き継いだ上限をリセットし、誤解を招くCFの統計ボックスも非表示にしています。
表示に関する変更だけであり、SE/MEの内容やCFの計算は変更していません。
最終的な再実行ログは`qa_<energy>_<species>_v2.log`です。

## 元のHelix解析と高purity KF解析の包括的な質量比較

[Au+Au 13.5 GeV FXTの比較図](legacy_vs_kf_mass_13p5.pdf)と
[Au+Au 3.85 GeV FXTの比較図](legacy_vs_kf_mass_3p85.pdf)では、
`analysis/anaLambdaNuclearId.C`（Helix Imp5）と
`StFemtoMaker + KF high purity`を比較しています。
どちらも同じ先頭10,000入力イベントを使用しています。左パネルは生のカウント、
右パネルは各ヒストグラムの[1.10,1.14) GeV/c2内のビン内容の合計が1になるように
正規化したものです。元のROOTヒストグラムは変更していません。

| データセット | 全質量範囲の生entries、Helix / KF | 表示窓内のビン内容の合計、Helix / KF |
|---|---:|---:|
| AuAu13p5 FXT | 7216 / 873 | 2438 / 758 |
| AuAu3p85 FXT | 1983 / 144 | 628 / 126 |

これは**再構成方法と最終カットの両方が異なる条件の比較**であり、
KFアルゴリズム単独の効果を取り出したものではありません。
カウントには背景も含まれるため、その比は検出効率ではありません。
背景差引きやpurityフィットは行っていません。
PDFを画像化し、両パネル、ラベル、カウント、表示範囲を目視確認しました。
