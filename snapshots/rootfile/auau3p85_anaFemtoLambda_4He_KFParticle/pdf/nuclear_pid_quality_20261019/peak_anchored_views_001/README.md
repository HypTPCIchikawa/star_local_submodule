# 元PID多項式に固定したHe／tピークの診断図

[比較PDF](peak_anchored_diagnostics.pdf)は2026-10-19作成、28頁です。
Au+Au FXT 3.85 GeV・2021 P24iy部分統合ROOT由来の保存済みALL分布を使用しました。
新しいイベント解析やfarm job投入は行っていません。

元の`log10(R)`多項式（中心3次・幅2次）から、t・³He・⁴Heの中心と幅を固定しました。
背景核種の中心・幅をHe4 fit内で独立に動かす方式ではありません。
同じALL内のt実ピークから⁴He右裾までを連続した局所範囲で同時fitしています。
dはfit成分から明示的に除外し、モデル依存の寄与上限を別途診断しました。

| R [GeV/c] | He領域の頁 | t領域の頁 |
|---|---|---|
| 0.825 | 1–2 | 3–4 |
| 0.875 | 5–6 | 7–8 |
| 0.925 | 9–10 | 11–12 |
| 0.975 | 13–14 | 15–16 |
| 1.725 | 17–18 | 19–20 |
| 1.775 | 21–22 | 23–24 |
| 1.825 | 25–26 | 27–28 |

各領域の最初の頁はGaussian、次の頁はlog-normalです。
各頁の上下はexponential／linear背景、左右はlinear／log表示です。
He領域には³He頂上と左肩、⁴Heの山を含め、t領域は別位置のtピーク付近を表示します。
表示のための再fitや規格化はしません。旧図は削除・上書きしていません。

全28件の数値収束、全shape固定、ROOT再読込み、入力SHA不変、全112panelとPDF全頁のreadbackを確認しました。
ただしjoint χ²/ndfは約1887–6928で、元曲線とのずれが残ります。
これは良好な物理fit・purityの認定ではなく、モデル改善のための診断です。
この28件をpurityの系統差やcutoff採用には使わず、未評価を低purityと置き換えません。
次は各核種の実ピークで独立校正し、滑らかな同じ多項式の係数を検証する必要があります。
