# 本番採用R範囲（2026-10-17）

R=|p/q|、単位GeV/c。区間は全て左端を含み右端を含みません。

| 核種 | 採用するR区間 | R≥2の追加条件 |
|---|---|---|
| d | [0.65,1.45), [1.50,1.70), [2.00,2.50) | 3.268773 < m² < 3.693147 |
| t | [0.80,1.35), [1.40,2.50) | 7.2564275 < m² < 8.2816925 |
| ³He | [0.75,2.50) | 1.78285 < m² < 2.06485 |
| ⁴He | [0.70,0.85), [0.95,1.75), [1.80,3.20) | dと同じm²窓 |

モデルの低い側のpurityが0.5以上で、fitの帰属・応答検査も通る領域だけを採用します。低Rは凍結済みの採用範囲を保持、高Rは全4モデルの支持を要求しています。未評価はpurity=0という意味ではありません。

- `accepted_ranges.tsv`：独立した本番境界試験・図の入力。
- `bin_decisions.tsv`：各0.05区間の採否、理由、purity低側、候補count。
- `production_domains.json`：下限とveto、入力SHA。
- `completed.json`：入力不変と出力SHA。

再現用は `tools/nuclear_pid_cutoff/prepare_production_ranges.py --help`。全パス・閾値・R境界を明示します。候補数・モデル感度を真の信号効率や信頼区間と同一視しません。このREADMEは実行完了後に追加した説明で、completedの出力SHA一覧対象外です。
