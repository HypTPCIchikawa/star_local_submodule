# 全面配置版PID比較レポート

`new_old_pid_final.pdf`は、確定済みの旧設定比較9枚とfit値比較14枚を、PNGの画素を変更せずに全面配置した23ページのPDFです。ROOT5のvector PDFで生じた余白の偏りを回避しました。元のvector PDFとPNGは保持しています。

合冊後の23ページすべてをGhostscriptで読み取り、構文・描画エラーがないことを確認しました。ページ数は23で、1ページ目と23ページ目を再描画して目視しました。`pdf_page_01.png`、`pdf_page_23.png`にその検査図を保存しています。

1–9ページは途中時点の設定比較をそのまま保存した歴史的なページです。その表の`current configured`にある⁴He `[3,4]` は、2026-10-17の最終本番設定切替**前**の窓です。今回のstudyおよび新本番は狭いD窓`3.268773 < m² < 3.693147`を使用し、10ページと親ディレクトリREADMEに区別を明記しています。TOFの中心・幅を新しくfitしたものではありません。

各ページの元PNGの順序・SHAは`context.json`、実際の生成コマンドは`command.json`、ツールのsnapshotは`source/`、製品のSHAは`completed.json`を参照してください。このREADMEは完了後に追加した補足です。
