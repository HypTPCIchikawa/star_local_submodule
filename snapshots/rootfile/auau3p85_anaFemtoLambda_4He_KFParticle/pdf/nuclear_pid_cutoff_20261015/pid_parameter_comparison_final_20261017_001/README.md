# PID設定と再評価したfitパラメータの比較（2026-10-17）

3.85 GeV・2021年P24iyの既存研究結果を用いた比較です。新たなイベント解析、fit、dE/dx校正係数の更新は、この描画処理では行っていません。

## 読むファイル

- 推奨：`raster_report_001/new_old_pid_final.pdf`。確定済みPNGをそのまま全面配置した23ページ版。全ページのPDF読取、ページ数、先頭・末尾の描画を検査します。
- `new_old_pid_final.pdf`：ROOT5のvector PDFを合冊した同じ23ページ。元vector PDFは保存していますが、ROOT5出力の構文補修警告とページ余白の偏りがあるため、通常は上の全面配置版を使用してください。
- `fitted_parameter_comparison.pdf`：fit値との比較を追加した14ページのみ。
- `fit_points.tsv`：全fit点、採否、中心・幅、設定値、残差・幅比。fit失敗点は削除せず残しています。
- `coverage.tsv`：モデル・核種・領域ごとの全点数、描画点数、帰属／参照条件を満たす点数など。
- `context.json`、`source/`、`completed.json`：入力元、固定したソース・設定・fit表、SHA256。

## 比較の意味

各核種について、左上は中心、右上は幅、左下は`(μ_config−μ_fit)/σ_fit`、右下は`σ_config/σ_fit`です。下段の設定値には新共通設定を用い、上段では旧canonical／旧専用legacy／新共通設定の3曲線を比較しています。

旧設定は`../pid_parameter_comparison_20261017_001/source/`の不変snapshotを正としています。本番mainconf切替後の現在のファイルを、旧設定として再読込していません。canonicalの旧⁴Heと新共通設定は同じfrom040校正なので、重なる曲線があります。旧専用d・t・³Heのlegacyとの違いは、それぞれの競合核のpullも含めて扱ってください。

Gaussianは平均・標準偏差、log-normalはmode・局所曲率幅です。有限R幅で投影した分布のfit幅は検出器固有の校正幅ではなく、この結果だけで本番PIDの中心・幅の式を置換していません。残差の誤差はfit誤差の対角項のみで、中心と幅の共分散・設定関数の不確かさは含みません。

色付き点は数値精度と帰属／参照の条件を満たす点です。灰色点は数値的な応答fitは安定していても、帰属／参照を確認できていない診断点です。これらの表示条件はpurityの全採用基準そのものではありません。特に⁴Heの高Rは背景を十分に拘束できない区間があり、図が描けても採用区間とは限りません。

## TOFの新旧について

1–9ページは保存時点の旧設定比較です。その中の⁴He `[3,4]` は**過去のtofExtended設定の広い窓**を指し、2026-10-17に切り替えた本番設定の窓ではありません。今回の⁴He高R studyと新本番では、保存済み`TAG_D`と厳密に同じ窓`3.268773 < m² < 3.693147`を使用します。

d・t・³Heのstudy窓も保存済みの±1.5σ窓です。TOF m²の中心・幅を今回改めてfitしたわけではありません。高RはTOFタグを通った試料に条件付けたpurity／応答であり、無条件のALL試料や核種の真値と同一視しないでください。dE/dxとm²のjointヒストは元ROOTに存在しないため、任意のm²窓へ変更したpurity評価はできません。
