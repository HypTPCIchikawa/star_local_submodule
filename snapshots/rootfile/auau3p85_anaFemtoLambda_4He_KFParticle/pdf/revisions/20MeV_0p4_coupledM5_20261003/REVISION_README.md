# 旧summaryの保存版

summaryの切替前の図・レポート・ログを、削除せず退避しました。保存版のrebin・表示条件は `revision_manifest.json` の `old_settings` を参照してください。
旧設定と生成コードは `source_snapshots/`、全移動ファイルのhashと移動対応は `revision_manifest.json` に保存しています。

旧JSONやマクロ内の絶対パスは歴史的記録としてそのままです。旧マクロをここから直接実行すると 現行出力先を参照するため、再計算時は別の出力ディレクトリへ新しく生成してください。
元ROOTと新しい質量low/high比較のサブディレクトリは変更していません。
