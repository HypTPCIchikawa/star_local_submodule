## 4. qhu1さんのΛ cut調査と考察

指定PDFのページ16、§2.3 / Fig.9と、`/star/u/qhu1/local_polarization/` 下のInterface / Finder / Topo / Maker / Tree読出し / mass描画マクロを追跡した。

| 主な条件 | qhu1現存コード | 現在のKF設定 |
|---|---|---|
| original daughter χ²primary | 両娘 ≥ 10 | 両娘 > 3 |
| parentに関連付けたdaughterのχ²primary | 下流で再度両娘 ≥ 10 | 同じ追加条件なし |
| FinderのPV–DV距離 l | 5 < l < 200 cm | 1 < l < 200 cm |
| Finderのl/σl | > 5 | > 3 |
| parent geometric χ²/NDF | < 10 | < 10 |
| parent PV topology χ²/NDF | **< 5** | **< 3** |

重要な注意:

- qhu1のparent topology `< 5` はFinder後のTopoで適用される。Finderの候補保存だけで調査を止めると見落とす。
- original daughterと再フィット後daughterのχ²primaryは同じ値ではない。上流の閾値だけ変えてもqhu1全経路とは一致しない。
- qhu1にはpTとTOFの下流選別もある。TOFは必須ではないが、存在する場合は上流3σ判定に加えて固定m²窓を使う。
- 現在側のparent topology `< 3`、Imp5のcos pointing・距離条件など、現在の方が厳しい項目もある。
- qhu1下流massは保存daughterの四元運動量和。現在の元parent `GetMass()`との定義差を分けて比較する。parentのPDG massを固定しているためにピークがきれい、とはこの経路からは言えない。
- Fig.9はcollider 7.7 GeV・20–50%。現在のFXT √sNN ≈ 5.2 GeV・0–80%と直接同等ではない。colliderのηやvertexをFXTへ単純コピーしない。
- 図は背景が小さいが、本文はsideband背景評価を行っている。「BGがゼロ」とは断定しない。現存描画マクロの`signal to noise`は計算上S/(S+B)であり、S/Bとは区別する。
- Fig.9生成時のコード版・設定は未特定。ユーザーにも心当たりなし。現存実行マクロ9.2 GeV / 描画マクロ19.6 GeVという差や、現存Tree読出しのη式の括弧問題もあり、出版図の厳密な再現とは扱わない。

詳しいcut表、行番号付き参照、定義、未確定事項、今後の優先順位、調査時SHA256は [比較・考察メモ](../../mdfiles/kfparticle/comparisons/kfparticle_lambda_qhu1_cut_comparison_20260908.md) に保存した。**この調査に基づくcut変更・再解析・S/B評価は未実施。**
