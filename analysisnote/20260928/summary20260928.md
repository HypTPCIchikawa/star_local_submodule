## 4. Purity studyと結果

### 4.1 最初の探索

[初回study](../../mdfiles/kfparticle/comparisons/lambda_kf_purity_study_20260927.md)では12軸から1,020条件を比較した。event単位のhashでtraining 4,958 / validation 5,042へ分割し、代表条件の選定はtraining側で行った。

単独では `minDecayLengthSignificance >= 5` が有望で、全体でpurity94.46%、信号保持率94.95%。これに `abs(nSigmaProton) <= 2.5` を追加した `choice_02` は94.77%、93.09%。高purity側の `choice_04` は98.08%、74.91%となり、後続研究の `old_aggressive` として固定した。

### 4.2 信号保持率約70%を許容したrefinement

[追加study](../../mdfiles/kfparticle/comparisons/lambda_kf_purity70_refinement_20260927.md)では9軸から3,756条件（baseline 1、single 37、pair 572、triple 3,146）を比較した。

default / near / farの各sidebandに対する信号保持率の最小値に70 / 75 / 80%の下限を課した。`nominal70` は適格条件中のdefault sideband名目purity最大、`robust70/75/80` はsidebandの変動と背景countのPoisson上限を用いる事前の順位付けで選んだもの。後者も背景モデルに依存しない保証ではない。

この段階では前回の両splitを既に見ているため、全10,000イベントでの**探索的refinement**である。旧splitは診断用であり、新しい独立holdoutとは扱わない。

以下は全10,000入力イベントに対応する比較。追加cut以外は標準KF Imp5を継承する。

| Selection | Additional / tighter cuts | Nwin | B | S | Purity [%] | Signal retention [%] |
|---|---|---:|---:|---:|---:|---:|
| KF Imp5 baseline | None | 1370 | 143.25 | 1226.75 | 89.54 | 100.00 |
| Initial choice_02 | abs(nSigmaProton) <= 2.5; minDecayLengthSignificance = 5.0 | 1205 | 63.00 | 1142.00 | 94.77 | 93.09 |
| old_aggressive | imp5MinDCAPion = 2.0 cm; minDecayLengthSignificance = 10.0 | 937 | 18.00 | 919.00 | 98.08 | 74.91 |
| robust80 | imp5MinDCAPion = 1.5 cm; maxChi2Ndf = 5.0; minDecayLengthSignificance = 8.5 | 1013 | 24.00 | 989.00 | 97.63 | 80.62 |
| robust75 | imp5MinDCAPion = 2.5 cm; maxChi2Ndf = 5.0; minDecayLengthSignificance = 9.5 | 949 | 18.00 | 931.00 | 98.10 | 75.89 |
| robust70 | imp5MinDCAPion = 1.75 cm; maxChi2Ndf = 5.0; minDecayLengthSignificance = 10.5 | 905 | 16.50 | 888.50 | 98.18 | 72.43 |
| nominal70 | abs(nSigmaProton) <= 2.5; maxDistanceToPv = 0.45 cm; minDecayLengthSignificance = 10.0 | 892 | 15.00 | 877.00 | 98.32 | 71.49 |

`imp5MinDCAPion` は元pion trackのgDCA、`maxChi2Ndf` はfinal Λ fit、`minDecayLengthSignificance` はPV constraint後のparentの崩壊長/誤差。Finder内部の似た名前の量とは区別する。

### 4.3 指標の定義と解釈上の注意

- 信号窓は **[1.110, 1.122) GeV/c²** に固定。default sidebandsは [1.098, 1.106)、[1.126, 1.134) GeV/c²。
- `B = 0.75 × (Nleft + Nright)`、`S = Nwin − B`、`purity = S/Nwin`。窓を狭めてpurityを上げたものではない。
- nominal70の背景込み候補数保持率は65.11%、背景差引き信号保持率は71.49%。10,000入力を7,000イベントに減らした意味ではない。
- 少数countの統計変動に加え、ピーク下へ外挿する背景曲率が大きな不確かさ。非負background fitによるpurity範囲はnominal70で約95.86–98.82%、robust70で約96.76–98.43%。**98%の点推定は得たが、98%以上を保証しない。**
- old_aggressiveに対する名目改善はnominal70でも約0.24 percentage points。大幅な改善や探索後の統計的有意性を主張しない。収量を無理に70%まで減らす必要もない。
- purityは質量ピークの純度で、feeddownを除くprimary-Λ purityではない。信号保持率は真の検出・再構成効率ではなく、pT / rapidity / lifetime受容域の変化は別途検証が必要。
