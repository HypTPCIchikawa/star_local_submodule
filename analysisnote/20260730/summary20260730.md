## 1. 開発内容 (Development Summary)

- **Lambda-Nucleus 解析スクリプト群の作成**
  - Lambda と原子核 (d, t, 3He, 4He) のフェムトスコピー解析を行うための実行マクロ (`analysis/anaFemtoLambda_*.C`, `analysis/run_anaFemtoLambda_*.C`) およびシェルスクリプト (`script/run_anaFemtoLambda_*.sh`, `script/singularity_run_anaFemtoLambda_*.sh`) を作成した。

- **`StLambdaNuclearMaker` のビルドシステムへの統合**
  - `StFemtoMakerLambdaNuclear` のクラス定義ファイル名およびディレクトリ構造を `StMaker/StLambdaNuclearMaker/StLambdaNuclearMaker.{h,cxx}` に変更し、STAR の `Makefile` の `MAKER_DIRS := $(wildcard StMaker/St*Maker)` ルールで自動的に `libStLambdaNuclearMaker.so` としてコンパイルされるように修正した。
  - C++ のネームスペーススコープの問題 (`StLambdaV0Reconstruction` とグローバルスコープの競合) などを解決し、Singularity 環境 (SL7) およびホスト (AL9) でコンパイルが通るようにした。

- **`test.root` が作成されない & 実行時 Abort エラーの修正**
  - `run_anaFemtoLambda_*.C` を実行した際に `Aborted (core dumped)` で落ち、`test.root` が出力されない問題を調査・修正した。
  - **原因1**: メイン設定ファイル (`config/mainconf/main_auau3p85_anaFemtoLambda_*.yaml`) のヒストグラム設定キーが `femtoLambdaNuclear:` になっていた。プログラム側は Maker 名 + "Hist" (`femtoLambdaNuclearHist:`) を期待していたため、ヒストグラム管理オブジェクト (`m_histManager`) が `NULL` となり、ファイル作成および出力処理全体がスキップされていた。
    - **対応**: 全てのメイン設定 YAML でキー名を `femtoLambdaNuclearHist:` に修正。
  - **原因2**: ヒストグラム設定ファイル (`config/hist/hist_auau3p85_anaFemtoLambda_*.yaml`) の 2次元ヒストグラム (`hKstarMass_CentBinX` 等) の定義において、`type: TH2F` の記述が欠落していたため、1次元 (TH1F) として扱われ初期化に失敗していた。
    - **対応**: Python スクリプトを使用し、該当する 2次元ヒストグラム定義に `type: TH2F` を追記。
